# 科学计算器 (Scientific Calculator)

一个功能丰富的科学计算器网页应用，支持基础运算和高级数学函数。

## 功能特性

### 基础运算
- ➕ 加法
- ➖ 减法
- ✖️ 乘法
- ➗ 除法

### 数学函数
| 按钮 | 功能 | 说明 |
|------|------|------|
| ± | 正负切换 | 将当前数值取反 |
| % | 百分比 | 将当前数值除以 100 |
| √ | 平方根 | 计算当前数值的平方根 |
| x² | 平方 | 计算当前数值的平方 |
| x³ | 立方 | 计算当前数值的立方 |
| 1/x | 倒数 | 计算当前数值的倒数 |
| xʸ | 幂运算 | 计算 x 的 y 次方 |

### 三角函数（角度制）
- sin - 正弦函数
- cos - 余弦函数
- tan - 正切函数

### 对数与指数
- log - 常用对数（以10为底）
- ln - 自然对数（以e为底）
- eˣ - 指数函数

### 常数
- π - 圆周率（3.14159...）

## 快速开始

### 开发模式

```bash
npm install
npm run dev
```

### 生产构建

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```

## 使用方法

1. 在浏览器中打开应用
2. 点击数字按钮输入数值
3. 点击运算符或函数按钮进行计算
4. 点击 `=` 按钮查看结果
5. 点击 `C` 按钮清除所有输入

## 分支说明

| 分支名 | 描述 |
|--------|------|
| main | 主分支，包含完整功能 |
| feature-ui | 静态UI布局 |
| feature-logic | 基础运算逻辑 |
| feature-functions | 基础函数功能 |
| feature-more-functions | 科学计算器函数 |
